# ATP Counselling & Coaching Website

A responsive website developed for **ATP Counselling & Coaching**. The website provides information about the practice, counselling services, contact details, and allows prospective clients to enquire about appointments.

---

## Features

- Responsive website design
- Home page
- About page
- Services page
- Contact page
- Thank You confirmation page
- WhatsApp integration
- Social media links
- Google Maps integration (Contact page)
- Contact form
- Mobile-friendly layout

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Font Awesome

## Installation

1. Clone the repository.

```bash
git clone https://github.com/Gaia-Kipling/ATP-V1.git
```

2. Open the project folder.

3. Open `index.html` in your preferred web browser.

No additional software or build tools are required.
